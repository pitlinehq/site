Privacy

Effective date: September 3, 2026. This notice is for Pitline Inc. (“Pitline,” “we”), a Delaware C-corporation, the public website at pitline.dev, and the Pitline client you install on your computer.

The Pitline client (the product)

The Pitline client is fully local. It does not include analytics, telemetry, crash reporting, usage tracking, or any other data collection by Pitline Inc. Agent sessions, terminals, approvals, and local configuration stay on your machine. This software does not phone home. If you bind the UI off loopback so you can open it over Tailscale or LAN, that traffic stays on the network you chose; it is not sent to Pitline Inc. If you connect a coding agent that has its own network use, that is that agent’s behavior, not Pitline sending product data to us.

This website (pitline.dev only)

pitline.dev is a static company site. We do not ask you to create an account here. We do not run a login, payment form, or newsletter signup on these pages.

These pages do not currently include Google Analytics or other analytics tags. We use Google Search Console to understand how pitline.dev appears in search; it does not receive your agent sessions. Our host, GitHub Pages, may keep ordinary request logs under its own policies. If we add website analytics, we will update this notice to describe what is collected. The Pitline client remains separate from this website.

Email

If you write to max@pitline.dev, we use your message to respond. We do not sell contact details.

What we are not claiming

A cloud subscription and a mobile app are planned. They are not available yet. When they exist, we will update this notice before collecting account or device data for those products.
