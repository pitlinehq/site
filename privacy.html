Privacy

Effective date: September 3, 2026. This notice is for Pitline Inc. (“Pitline,” “we”), a Delaware C-corporation, the public website at pitline.dev, and the Pitline client you install on your computer.

The Pitline client (the product)

The Pitline client is fully local. It does not include analytics, telemetry, crash reporting, usage tracking, or any other data collection by Pitline Inc. Agent sessions, terminals, approvals, and local configuration stay on your machine. This software does not phone home. If you connect a coding agent that has its own network use, that is that agent’s behavior, not Pitline sending product data to us.

This website (pitline.dev only)

pitline.dev is a static company site. We do not ask you to create an account here. We do not run a login, payment form, or newsletter signup on these pages.

Website analytics apply only to these public pages. Google Analytics 4 on pitline.dev (when the tag is present) measures visits to this site — for example page path, approximate geography, and device type. That measurement is not in the Pitline client and is not a feed of your agent sessions. Google Search Console is used so we can see how this site appears in Google Search. Both are website-only. If our host (GitHub Pages) or your browser keeps ordinary request logs, that is separate from the product; we do not sell that information.

Email

If you write to max@pitline.dev, we use your message to respond. We do not sell contact details.

What we are not claiming

A cloud subscription and a mobile app are planned. They are not available yet. When they exist, we will update this notice before collecting account or device data for those products.
