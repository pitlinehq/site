A few useful answers

Before you start.

Does Pitline replace my coding agent?

No. Pitline gives you a browser interface for supervising the agents you already use. Install and authenticate each agent separately. Its provider’s terms, subscriptions, and usage charges still apply.

Can I use it from my phone?

Yes, through your phone’s browser when it can reach the machine running Pitline. Use a private network such as Tailscale and configure access appropriately. A native mobile app and hosted cloud access are planned, not available today. Set up access.

Can I approve every request from every agent?

Approval support depends on the agent, the request, and who owns the session. Start a managed session in Pitline for supported controls. External Claude hook approvals require separate setup; plain terminal access does not provide structured approval support. Compare integrations.

What happens when I close my browser?

The session continues on the host machine, and you can reconnect. The keeper service allows native terminal sessions to survive daemon restarts. The host still needs to stay awake and running; this does not keep tasks executing during sleep or shutdown.

Does my code go through Pitline’s servers?

The local product does not send your sessions, code, analytics, or telemetry to Pitline Inc. Browser connections go to your machine over the network you choose. Your coding agent may contact its own provider as usual. Read the privacy notice.

What does it cost, and where is the source?

The local Pitline software is licensed under Apache-2.0 and requires no Pitline subscription. Agent-provider costs are separate. Browse the source. A future cloud subscription is not available to purchase today.

Which platforms and session providers are supported?

Pitline runs on macOS and Linux, with Intel/Apple Silicon and x86_64/ARM64 builds respectively. Native terminals and local Herdr sessions are supported. tmux integration is coming soon. There is no native Windows release.
