Install

Pitline is a client you run on your own computer. It does not send analytics, telemetry, crash reports, or session data to Pitline Inc. Agent sessions, terminals, and config stay on that machine unless you send them somewhere yourself.

Google Analytics, if present, is only on this website (pitline.dev). It is not in the product.

macOS and Linux

Binaries are published to the public pitlinehq/releases repo (source stays in a private repository). After the first version tag, install with:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pitlinehq/releases/releases/latest/download/pitline-installer.sh | sh

Then install the background service (daemon + keeper):

pitline install-service

Open the local UI at http://127.0.0.1:7337 and run pitline doctor if something looks off.

No installer is published yet. That curl will 404 until we cut the first release. Until then, people with source access can build with cargo install --path crates/pitline from a private clone.

From another device (Tailscale)

Pitline does not ship a cloud or a mobile app. The UI is still the local daemon in a browser. To open it from a phone or another computer on your tailnet (or LAN), bind off loopback in config:

bind = "0.0.0.0:7337"

Then visit http://<this-machine's-Tailscale-IP>:7337. That traffic stays on your network. It is not a Pitline Inc. service and it does not send sessions to us.

Local auth is off by default, so anyone who can reach that port can control your agents. Use Tailscale ACLs, or set local_auth = "token" and sign in with the value from pitline token.

Homebrew

Once the first public binary release exists:

brew install pitlinehq/tap/pitline
pitline install-service

The formula downloads the same prebuilt archives from pitlinehq/releases. The tap is pitlinehq/homebrew-tap.

macOS without a Developer ID signature

Until Pitline Inc.’s Apple Developer org is approved and we ship Developer ID–signed + notarized builds, macOS Gatekeeper will treat the download as unsigned. That is expected. You are installing software you chose from our public releases; this is not an App Store build.

After the curl installer or Homebrew finishes, clear the quarantine flag macOS adds to downloaded files:

# if pitline landed in ~/.local/bin (curl installer default)
xattr -d com.apple.quarantine ~/.local/bin/pitline 2>/dev/null || true

# Homebrew keg (path varies by Intel vs Apple Silicon)
xattr -dr com.apple.quarantine "$(brew --prefix)/Cellar/pitline" 2>/dev/null || true

Then run:

pitline install-service
pitline doctor

If macOS still blocks it (“cannot be opened because the developer cannot be verified”):

  1. Open System Settings → Privacy & Security.
  2. Find the message about pitline being blocked and choose Open Anyway (you may need to scroll).
  3. Confirm again if prompted, then re-run pitline doctor.

Or in Finder: locate the pitline binary, Control-click (right-click) → Open, then confirm. Do this once; later launches from Terminal should work.

If launchd refuses the service after install, unload and retry after the Open Anyway step:

launchctl bootout "gui/$(id -u)/com.pitline.daemon" 2>/dev/null || true
launchctl bootout "gui/$(id -u)/com.pitline.keeper" 2>/dev/null || true
pitline install-service

Signed and notarized Mac builds will replace this section when Apple enrollment is done. There is still no App Store or iOS app.

What you should know

  • There is no App Store build and no iOS app.
  • The installer puts pitline on your PATH (typically ~/.local/bin). It does not create a Pitline Inc. account or phone home.
