Install

Pitline is a client you run on your own computer. It does not send analytics, telemetry, crash reports, or session data to Pitline Inc. Agent sessions, terminals, and config stay on that machine unless you send them somewhere yourself.

Google Analytics, if present, is only on this website (pitline.dev). It is not in the product.

macOS and Linux

Binaries are published to the public pitlinehq/releases repo (source stays in a private repository). After the first version tag, install with:

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pitlinehq/releases/releases/latest/download/pitline-installer.sh | sh

Then install the background service (daemon + keeper):

pitline install-service

Open the local UI at http://127.0.0.1:7337 and run pitline doctor if something looks off.

No installer is published yet. That curl will 404 until we cut the first release. Until then, people with source access can build with cargo install --path crates/pitline from a private clone.

What you should know

  • macOS Gatekeeper: until Pitline Inc.’s Apple Developer org is approved and we sign with Developer ID + notarize, macOS may block the unsigned binary. That is expected.
  • Homebrew is not set up yet (no pitlinehq/homebrew-tap).
  • There is no App Store build and no iOS app.
  • The installer puts pitline on your PATH (typically ~/.local/bin). It does not create a Pitline Inc. account or phone home.
