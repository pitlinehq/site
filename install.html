Install Pitline

Supervision for AI coding agents, on your machine. No account. No telemetry from the product.

1. Install the binary

Pick one. Homebrew or the curl installer both put pitline on your PATH.

Homebrew

brew install pitlinehq/tap/pitline

Curl installer

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pitlinehq/releases/releases/latest/download/pitline-installer.sh | sh

2. Allow the unsigned build

Mac builds are not Developer ID–signed yet. After install, clear the quarantine flag macOS adds to downloads:

xattr -d com.apple.quarantine ~/.local/bin/pitline 2>/dev/null || true
xattr -dr com.apple.quarantine "$(brew --prefix)/Cellar/pitline" 2>/dev/null || true

If macOS still says the developer cannot be verified: System Settings → Privacy & Security → Open Anyway, or Control-click the binary in Finder → Open once.

3. Start the service

pitline install-service
pitline doctor

Open http://127.0.0.1:7337 in your browser.

If the service will not start

After Open Anyway, reset the agents and install again:

launchctl bootout "gui/$(id -u)/com.pitline.daemon" 2>/dev/null || true
launchctl bootout "gui/$(id -u)/com.pitline.keeper" 2>/dev/null || true
pitline install-service

4. Use from another Mac or phone on your Tailscale

Bind off loopback, then open the UI at your Mac’s Tailscale IP. pitline bind updates config and restarts the service when installed. Keep auth off only on a network you trust—or set local_auth = "token".

Show the current listen address:

pitline bind

Listen on all interfaces (LAN / Tailscale):

pitline bind 0.0.0.0:7337

Change only the port (keeps the current host):

pitline bind 8443

1. Install the binary

Pick one. Both put pitline on your PATH (often ~/.local/bin).

Curl installer

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pitlinehq/releases/releases/latest/download/pitline-installer.sh | sh

Homebrew (Linuxbrew)

brew install pitlinehq/tap/pitline

2. Start the service

pitline install-service
pitline doctor

install-service writes and enables the systemd user units. Enable linger so they keep running after logout:

loginctl enable-linger $USER

Open http://127.0.0.1:7337 in your browser.

3. Use from another device on your Tailscale

Bind off loopback, then open the UI at this machine’s Tailscale IP. pitline bind updates config and restarts the service when installed. Use Tailscale ACLs, or set local_auth = "token".

Show the current listen address:

pitline bind

Listen on all interfaces (LAN / Tailscale):

pitline bind 0.0.0.0:7337

Change only the port (keeps the current host):

pitline bind 8443

Pitline runs on your machine. No Pitline Inc. account. The client does not send analytics or telemetry.
