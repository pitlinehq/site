Install Pitline

Start supervising your coding agents from your browser. Pitline runs on your machine, with no Pitline account required.

Use macOS or Linux. Install and sign in to your preferred coding agent on the same machine first; Pitline uses that local agent installation and its existing provider account.

1. Install the binary

Run the installer in your terminal, then follow its PATH instructions. Open a new terminal if needed.

Shell installer
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pitlinehq/releases/releases/latest/download/pitline-installer.sh | sh

Prefer a manual install? Download the archive for your operating system and processor from the latest release, verify it against the accompanying checksum, then extract pitline into a directory on your PATH. Read the release notes for build requirements.

If macOS blocks an unsigned build

Check the release notes for signing status. For an unsigned download you trust, try launching it once, then use System Settings → Privacy & Security → Open Anyway if macOS offers that option. Allow the binary before installing the service.

2. Start the service

Start and check Pitline
pitline install-service
pitline doctor

The service installer sets up launchd agents for Pitline and its terminal keeper.

Open http://127.0.0.1:7337 on this computer. If token authentication is enabled, run pitline token and enter its value in the browser’s sign-in form.

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pitlinehq/releases/releases/latest/download/pitline-installer.sh | sh

2. Start the service

Start and check Pitline
pitline install-service
pitline doctor

The service installer sets up systemd user services and attempts to enable linger so they survive logout. If it reports a linger warning, follow the command it prints. Linux installations without systemd user services need a separate process supervisor.

Open http://127.0.0.1:7337 on this computer. If token authentication is enabled, run pitline token and enter its value in the browser’s sign-in form.

3. Start your first agent

  1. Choose New agent and select an installed agent.
  2. Choose your project under Launch folder, select Chat, then choose Start for that agent.
  3. Send a small task, such as “Explain this project’s structure.” Follow the response and tool activity in Chat.
  4. When a supported permission request appears, inspect it and approve or deny it. Available controls depend on the agent and how the session was started.

Use the agent compatibility guide to understand managed and external sessions. If your project is missing, see launch-folder setup.

4. Open Pitline on your phone

Connect your computer and phone over a private network, enable token authentication, and open your computer’s private address in the phone’s browser. Follow the remote-access guide before changing the listening address.
